# ru-bank-clientbank @ 1.0.0

Шаблон правил классификации для **российских банковских выписок** (ClientBank / текст назначения).

## Состав

32 правила на базе `CONDITION_KEYS` (без ИНН-fallback, без regex). Приоритеты набора: **1000 + local_priority** — пользовательские правила с меньшим числом всегда сильнее.

## Hold-out (обязателен до prod-enable)

Набор **не считается принятым**, пока владелец локально (не CI, не staging) не подтвердит:

1. **Второй календарный месяц** или **другой банк** (другая структура фраз).
2. Сверку сумм по секциям ОДДС с эталоном (карточка 1С / агрегаты), без вывода сырых назначений в отчёты.
3. Явное решение владельца включить pack для клиентов (`classification_packs_enabled` на стенде).

До hold-out флаг **`classification_packs_enabled`** остаётся **false**; API pack → 404.

## Проценты по депозитам

Правило `deposit_interest_payout` (`ПРОЦЕНТОВ ПО ДЕПОЗ` → **investing**) — решение владельца 2026-10-27, см. FA-R06.1 §3.3.
