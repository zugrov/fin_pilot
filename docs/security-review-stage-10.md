# Разбор безопасности этапа 10

Дата: 2026-10-14. Это чтение кода и локальных тестов, не пентест и не проверка боевого контура.

## Сессия и CSRF

Изменяющие запросы читают cookie сессии и сверяют заголовок `X-CSRF-Token` с секретом сессии через `compare_digest`. Несовпадение даёт 403. Чужой `X-Tenant-Id` не открывает чужое пространство: членство проверяется на сервере.

## RLS

Таблицы клиента включены в row level security. Запрос идёт с `app.current_tenant_id` и `app.current_user_id`. Политика чужого пространства в тестах не возвращает строки.

## Оплата и обход

`BILLING_GUARD_BYPASS` в production отвергается при старте. Вне production обход существует для тестов и не заменяет платёж. Return URL доступ не открывает: активация идёт после чтения платежа через API провайдера и одной записи в базе.

Webhook YooKassa только кладёт уведомление в `billing_webhook_inbox` и отвечает `ok`. Он не вызывает активацию. Повтор того же события не создаёт вторую строку.

## Почта

Ответ источника возвращает host, папку, отправителя и username. Пароль и `encrypted_credentials` в ответ не входят. В `backend/app` нет вызовов logger, которые печатали бы пароль или тело вложения. `POLL_IMAP`, `SEND_REAL_EMAIL`, `SEND_EXTERNAL_MESSAGES` и `SEND_LIVE_PAYMENTS` по умолчанию выключены. Production не стартует с `POLL_IMAP` и ключом шифрования по умолчанию.

## Что не менялось

Нарушений этих правил в коде этапа не найдено, поэтому точечных исправлений нет. Новых таблиц и ролей нет.

## Что этот разбор не закрывает

Боевой webhook не зарегистрирован. Живой IMAP, SMTP и Telegram не включались. Docker, TLS и внешнее хранение копий не проверялись.
