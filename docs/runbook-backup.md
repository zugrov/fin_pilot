# Копия и восстановление

Локальный прогон на порту 5433 не закрывает пункт готовности «проверенное восстановление backup». Он не доказывает копию вне сервера и не подтверждает RPO 24 часа и RTO 4 часа.

## Что копируется

- База `finpilot_test` в custom-формате `pg_dump`.
- Каталог вложений импорта.
- Оба архива шифруются `openssl enc -aes-256-cbc -pbkdf2`. Пароль только из `BACKUP_PASSPHRASE`. Без пароля файл не создаётся.

Redis не источник истины. Очереди писем, платежей и Telegram восстанавливаются из таблиц outbox в базе.

## Команда

Из каталога `backend`, пароль в окружении процесса, не в git:

```
BACKUP_PASSPHRASE='…' TEST_PG_PORT=5433 uv run python scripts/backup.py \
  --storage var/imports --output /путь/вне/репозитория/finpilot.enc
```

Восстановление всегда идёт в новую базу `finpilot_restore` и не трогает `finpilot_test`. Порт 5432 и база `finpilot` отклоняются.

```
BACKUP_PASSPHRASE='…' TEST_PG_PORT=5433 uv run python scripts/restore.py \
  --input /путь/вне/репозитория/finpilot.enc --storage /путь/восстановленных-вложений
```

После проверки базу `finpilot_restore` удаляют.

## Хранение

Вне сервера: 14 дневных и 8 недельных копий. Этот репозиторий расписание и внешний диск не включает. Срок хранения вложений импорта и финансовых документов согласуется отдельно и здесь не сокращается.
