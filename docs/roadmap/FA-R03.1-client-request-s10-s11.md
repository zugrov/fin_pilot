## Текст для бухгалтерии (можно копировать)

**Тема:** Выгрузки 1С для настройки FinPilot — август и сентябрь 2026 (доработка пакета)

Здравствуйте!

Для настройки связки **«банк → учёт → дебиторка»** в FinPilot просим стандартные отчёты из **1С:Бухгалтерия 3.0**. Ниже — что выгрузить, в каком порядке удобнее делать на одной сессии и куда не класть лишнее.

### Шаг 0 — справка о версии (один раз)

1. В клиенте 1С: **Справка → О программе** (на том компьютере/сессии, где делаете выгрузки; если база серверная — на рабочем месте бухгалтера, подключённом к этой базе).
2. Сохраните **скриншот** или перепишите строку с **версией платформы** вида **8.3.х.хххх** (не путать с номером конфигурации «Бухгалтерия 3.0.206» — нужен именно релиз **платформы**).

### Шаг 1 — август 2026: расчётный счёт **51**

Порядок внутри месяца:

1. **Выписка (обмен с банком)** за **01.08.2026–31.08.2026**  
   - Раздел **Банк и касса** → обмен с банком / загрузка–выгрузка (название пункта зависит от релиза) → **выгрузка** выписки в текстовый файл формата **1CClientBankExchange** (иногда подпись **«Клиент-Банк»**, расширение **`.txt`**).  
   - Кодировка — как предлагает 1С для обмена (часто **Windows cp1251**). Не конвертировать файл в UTF-8 без согласования.

2. **Карточка счёта 51** за тот же период  
   - **Отчёты** → **Карточка счёта** → счёт **51** → период **август 2026** → выгрузка в **Excel** (`.xls` / `.xlsx`).

3. **Оборотно-сальдовая ведомость по счетам (ОСВ)** за **август 2026**  
   - **Отчёты** → **ОСВ по счетам** → период **август 2026** → Excel.  
   - Нужна ведомость, где видны обороты и сальдо по **51** и типовой иерархии счетов (как в вашей обычной бухгалтерской печати).

### Шаг 2 — август и сентябрь 2026: дебиторка и реализация

Для **каждого** месяца (**08.2026** и **09.2026**) отдельно:

4. **Карточка счёта 62** (**S10**)  
   - **Отчёты** → **Карточка счёта** → счёт **62** (при необходимости бухгалтер может уточнить аналитику) → полный месяц → Excel.

5. **Журнал реализации** (**S11**)  
   - **Отчёты** (или **Продажи**, в зависимости от релиза) → **Журнал документов** по **реализации** (товары, услуги, УПД) за полный месяц → Excel.  
   - Нужны документы, которые отражают **начисление выручки** и связь с покупателями (для сверки с оплатами на **51**).

*(ОСВ по **62** за эти месяцы у нас уже есть; повторно выгружать **S9** не обязательно, если ничего не менялось.)*

### Зачем это FinPilot

- **51 + выписка** — денежный поток и сверка с банком.  
- **62 + журнал реализации** — связь **оплаты на расчётный счёт ↔ выручка ↔ долг/аванс покупателя**, а не только остаток по **51**.

Файлы передаём **владельцу проекта** для локальной настройки; **не** для публикации в интернет и **не** в открытый мессенджер.

## Что **не** присылать

- Пароли и логины (1С, банк-клиент, VPN, SSH, API-ключи).
- Файлы ключей, сертификаты ЭП, токены банка.
- Полные выгрузки базы **`.dt`**, бэкапы СУБД, каталоги **всей** номенклатуры/кадров «на всякий случай».
- Лишние персональные данные **не по сути** (паспорта, зарплатные ведомости сотрудников, медданные и т.п.) — в отчётах по **51/62** обычно достаточно штатных полей 1С по контрагентам.
- Открытые ссылки на облако без пароля в общем чате — только согласованный защищённый канал.
