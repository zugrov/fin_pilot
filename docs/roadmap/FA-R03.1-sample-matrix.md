## 3. Правила обезличивания (до выноса файла из контура клиента)

1. **Согласие клиента** на передачу обезличенных копий — **обязательно** (см. STATE `client_data_handling`).
2. Обезличивание выполняется **на стороне клиента или под его контролем** до того, как файл покидает контур клиента.
3. **Единая таблица замен** на весь пакет одного месяца:
   - контрагенты → `COUNTERPARTY_001`, `COUNTERPARTY_002`, … (**сохранять связи** между файлами);
   - ИНН/КПП → синтетические с сохранением **уникальности** и **ссылок**;
   - номера счетов → `40702810…001`, … (**сохранять связи** с контрагентами).
4. **Суммы, даты, валюта, знаки операций не менять.**
5. Обезличенные файлы — только в **`var/fa-r03-deidentified-samples/`** (gitignored); не staging, не мессенджеры, не email без отдельного решения.
