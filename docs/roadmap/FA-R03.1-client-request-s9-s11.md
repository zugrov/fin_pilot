# FA-R03.1 · Передача образцов S9–S11 (август и сентябрь 2026)

**Назначение:** чек-лист и формулировки для **внутренней** передачи файлов (не публичный запрос «клиенту»).  
**Контур:** **ООО «ТОПКОМ»** — первая пилотная организация, **собственная компания владельца** проекта; файлы передаёт **владелец** локально в `var/` (gitignored). **ООО «Топ»** на staging — **синтетика**, не ТОПКОМ.

**Не** вкладывать выгрузки в git, staging без отдельного решения и правовых предпосылок (см. DECISIONS · D6 ТОПКОМ).

## Текст для согласования с бухгалтерией ТОПКОМ (можно копировать)

Тема: **Выгрузки 1С для настройки FinPilot — август и сентябрь 2026**

Для настройки управленческой связки **«банк → учёт → дебиторка»** нужны стандартные отчёты 1С (**Бухгалтерия 3.0**) за **август и сентябрь 2026**:

1. Журнал документов **«Реализация»** за месяц.  
2. **Карточка счёта 62** за месяц.  
3. **ОСВ по счёту 62** (по контрагентам) за месяц; при наличии — отдельно **62.01** и **62.02**.

Выписка и карточка **51** за эти месяцы уже используются для сверки денежного счёта. Перечисленные отчёты нужны, чтобы замкнуть цепочку **«поступление на расчётный счёт → выручка → задолженность/аванс покупателя»**, а не только «деньги ↔ 51».

Файлы передаются **владельцу проекта** для локальной настройки; **не** для публикации в интернет и **не** в репозиторий кода. Обработка — на стороне владельца в согласованном контуре (см. решения по изоляции пилота D6).
