## 2. Проверки при получении (без ПII в протоколе git)

### 2.1 Общие

- [ ] Период отчёта — **полный календарный месяц** (1-е — последний день).
- [ ] Формат **`.xls` или `.xlsx`**, открывается `xlrd`/Excel без макросов.
- [ ] Имя файла и `MANIFEST.txt` в `var/` (local only) — без текстов назначений в git.

### 2.2 S9 · ОСВ 62 по контрагентам

- [ ] Есть строки контрагентов и строка **«Итого»** (или эквивалент иерархии).
- [ ] Сумма оборотов по строкам = оборот счёта **62** в **S3** (тот же месяц), допуск **0,00**.
- [ ] Начало/конец месяца согласуются с **S9a+S9b** (если есть): авансы vs долг не смешаны в одной строке «итого по контрагенту» без расшифровки.

### 2.3 S10 · карточка 62

- [ ] Оборот **Дт/Кт** за месяц = **S9** / **S3** по счёту 62, допуск **0,00**.
- [ ] Сальдо на начало/конец = **S9** на те же даты.
- [ ] **Перекрёст с карточкой 51:** сумма **поступлений** на 51 с корр. **62.01** / **62.02** (из **S2**, тот же месяц) согласуется с **оплатами** по карточке 62 (не обязана совпадать 1:1 по дням, но порядок величины и знак — без немотивированного расхождения > согласованного допуска; расхождения — в локальный протокол).

### 2.4 S11 · журнал реализаций

- [ ] Документы реализации за месяц; суммы **Дт/Кт** / выручка согласуются с **оборотами 62** и **90.01** в **S3** (контроль high-level).
- [ ] Даты документов покрывают месяц; нет «пустого» месяца.

## 3. Критерии «принято» (локальная приёмка образца)

| Критерий | Принято |
| --- | --- |
| Комплект S11+S10+S9 за месяц полный | да/нет |
| Итоги 62 = S3/S9, допуск 0,00 | да/нет |
| Перекрёст 51↔62 (поступления corr. 62.xx) проверен | да/нет |
| Файлы только в `var/`, git clean | да |

**Не принято:** неполный месяц; нет итоговой строки; расхождение с S3 > 0,00 без объяснения; файл только в чате/email без локального gitignored хранения.

## 4. План локального разбора (без записи в продукт)

1. **Парсер:** расширить read-only слой `app/domain/imports/fa_r03/xls_reader.py` (или отдельный модуль `fa_r03/sales_journal.py`) по образцу карточки 51 — **только** после приёмки файла.
2. **CLI:** опциональный режим `fa_r03_check --sample-dir …` для S10/S11 (как S2/S3), **вне CI**, вывод — агрегаты без контрагентов.
3. **Сверки:** контрольные суммы в локальный `var/…/FA-R03.1_samples_analysis_LOCAL.md`; **не** `ImportBatch`, **не** staging.
4. **Приёмка парсера:** unit-тесты на **синтетических** xls-fixtures в repo; реальные `.xls` — только локально.
