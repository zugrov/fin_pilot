# FA-R03.2 · Персональный список выгрузок (по профилю организации)

**Статус:** спецификация для продукта и бухгалтерии; **только текст**, без кода.  
**Связь:** профиль организации — [ADR-003](ADR-003-organization-profile-and-tax-rules.md).

Ниже — **шаблон**: по заполнению **`accounting_source`**, **`money_channels`**, **`industry_sphere`**, **`vat_status`** формируется **перечень отчётов**, **формат**, **период** и **как получить** в типовой **1С:Бухгалтерия** (порядок кнопок может отличаться по релизу; названия отчётов согласовать с бухгалтером).

---

## Общие правила

| Элемент | Правило |
| --- | --- |
| **Период** | Полный календарный **месяц** (1 — последний день) для операционной сверки; **год** — для порогов НДС / справочных разрезов. |
| **Формат** | По умолчанию **`.xls` / `.xlsx`** без макросов; **ClientBank** — **текст** в кодировке, которую принимает импорт (**Windows cp1251** — встречается в выписках Сбербанка). |
| **Хранение** | Файлы клиента — **только локально** (`var/` или иной согласованный каталог), **не git**. |

---

## Базовый набор (рынок: учёт в 1С, УСН, банк + эквайринг)

Покрывает денежный контур, выручку, дебиторку и транзит эквайринга **57.03**. Детализация по субсчетам **62.01 / 62.02** — по политике учёта.

| ID | Отчёт (название в 1С) | Зачем | Формат | Период | Как выгрузить (обобщённо) |
| --- | --- | --- | --- | --- | --- |
| **S1** | Выписка банка (ClientBank) по расчётному счёту | Поступления/списания, самоконтроль эквайринга | `.txt` | Месяц | Обмен с банком → выгрузка в формате **1CClientBankExchange** |
| **S2** | Карточка счёта **51** | Корреспонденции с **62.xx**, **90.01**, **91.02** | `.xls(x)` | Месяц | Отчёты → Карточка счёта → счёт **51** |
| **S3** | ОСВ (оборотно-сальдовая) по счетам | Эталон **90.01**, **57.03**, **62**, **91** | `.xls(x)` | Месяц | Отчёты → ОСВ по счетам → нужные счета / всё |
| **S9** | ОСВ по счёту **62** (по контрагентам) | Дебиторка | `.xls(x)` | Месяц | ОСВ с разбивкой по контрагентам для **62** |
| **S9a/S9b** | ОСВ **62.01** / **62.02** | Долг vs аванс | `.xls(x)` | Месяц | Отдельные выгрузки по субсчетам, если в **S9** смешанно |
| **S10** | Карточка счёта **62** | Связка оплат и оборотов **62** | `.xls(x)` | Месяц | Карточка счёта **62** |
| **S11** | Журнал документов **Реализация** (или аналог) | Контроль начислений выручки | `.xls(x)` | Месяц | Отчёты / журналы по типу документа |
| **S12** | ОСВ или анализ по **57.03** | Дт **57.03** по дням (эквайринг) | `.xls(x)` | Месяц | По согласованию с бухгалтером (детализация по дням) |
