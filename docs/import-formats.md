# Форматы импорта этапа 4

Поддержаны только эти контракты. Неизвестный заголовок, кодировка или версия отклоняются кодом `unsupported_format`. Универсальное чтение отчётов 1С не заявляется. Fixtures синтетические: `backend/tests/fixtures/imports/`.

## cash_transactions.csv и такой же лист XLSX

Колонки строго в этом порядке:

`external_id,wallet_code,business_date,direction,amount,currency,counterparty_inn,counterparty_name,description,document_number,category_code,direction_code`

- Дата `YYYY-MM-DD`.
- Сумма больше нуля, до копейки, разделитель точка. Число Excel с плавающей точкой отклоняется.
- `direction`: `in` или `out`. Знак суммы направление не задаёт.
- Валюта только `RUB`.
- `wallet_code` — код кошелька фирмы.
- Формула в сумме без значения отклоняется.
- Кодировка профиля: `utf-8`, `utf-8-sig` или `cp1251`.

## ClientBankExchange 1.03

Первая строка `1CClientBankExchange`, поле `ВерсияФормата=1.03`. Другая версия отклоняется.

Документ между `СекцияДокумент` и `КонецДокумента`. `ДатаСписано` — выплата, `ДатаПоступило` — поступление. Оба поля или ни одного — ошибка строки. `Номер` — внешний идентификатор, `Сумма` — сумма, `НазначениеПлатежа` — описание. Кошелёк берётся из привязки источника, не из файла.

## Дедупликация

Повтор байтов файла не создаёт операций. Тот же `external_id` и тот же payload — повтор. Изменённый payload — ревизия существующей операции. Одинаковые дата, сумма и описание с разными `external_id` одного источника — две операции. Единственное совпадение из другого источника связывает вторую source identity с той же операцией. Несколько совпадений остаются в review и не проводятся.
