# Hold-out: `tools/august_card51_reconcile.py`

Локальный audit-скрипт (**не** product API, **не** CI). Сравнивает **секции ОДДС** по строкам карточки счёта **51** (эталон по корр. счёту) с секциями **posted** `cash_transactions` в demo-БД за **август 2026**.

**Данные клиента** (.xls) **не** хранятся в git. Пути передаются аргументами.

**Безопасность:** `--database-url` принимается **только** для **localhost** (`127.0.0.1`, `localhost`, `::1`). Подключение к staging, VPS или prod **отклоняется** (exit code **3**).

## Что проверяет

- Для каждой строки карточки 51 за **2026-08**: направление, дата, сумма, корр. счёт → ожидаемая секция (`cash_flow_sections.py`).
- В БД: та же дата/направление/сумма → фактическая секция категории (`unmapped`, если категории нет).
- Считает совпадения и расхождения **без** названий контрагентов и назначений.

## Запуск

```bash
cd backend
uv run python ../tools/august_card51_reconcile.py \
  --card-xls /path/to/card51-august.xls \
  --database-url "postgresql://USER:PASS@127.0.0.1:5433/finpilot_demo_real_r03" \
  --company-id "<uuid компании FA-R03 2026-08>"
```

## Ограничения

- Один месяц, один профиль счетов; не доказательство для других банков/месяцев.
- Сопоставление cash ↔ строка карточки — по **(дата, направление, сумма)**; при коллизиях возможны ложные несовпадения.
- Не заменяет `fa_r03_check` и MVP сверки FA-R03.2.
